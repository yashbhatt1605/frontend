# CarXpress design update

## Included
- User showroom: restrained premium automotive styling with black, silver, and white accents.
- Admin workspace: charcoal dashboard with violet/purple accents, fine borders, and compact navigation.
- Light/Dark toggle in the user navbar and admin top bar.
- Theme preference saved in browser local storage (`carxpress-theme`).
- Existing routes, providers, page components, API services, and JSX class names are preserved; changes focus on theme wiring and presentation.

## Run
From this folder in PowerShell:
```powershell
npm install
npm start
```

This archive updates the frontend only. The backend API must still be running separately for live data.
